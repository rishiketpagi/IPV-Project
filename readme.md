# Image Vault V2

A clean Streamlit project for image-in-image steganography with a better UI and modular file setup.

## Features
- Upload cover image
- Upload secret image
- Encode secret image into cover image
- Download encoded PNG
- Upload encoded image later
- Decode and recover hidden image
- Side-by-side previews
- Difference map visualization
- Capacity estimate

## Project setup
```bash

pip install -r requirements.txt
streamlit run app.py
